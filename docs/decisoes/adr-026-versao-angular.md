# 📄 ADR-026 — Versão do Angular

---

## Status

Aceito

---

## Contexto

O frontend será desenvolvido com Angular, exigindo uma versão moderna para melhor performance e experiência.

---

## Decisão

Utilizar:

```text
Angular 21
```

---

## Consequências

### Positivas

* melhorias de performance
* melhor experiência de desenvolvimento
* suporte a novos padrões

---

### Negativas

* possíveis mudanças de API
* dependência de atualização constante
