# 📄 ADR-004 — Banco de Dados Relacional

---

## Status

Aceito

---

## Contexto

O sistema possui forte necessidade de consistência e integridade.

---

## Decisão

Utilizar:

```text
PostgreSQL (banco relacional)
```

---

## Consequências

### Positivas

* integridade referencial
* queries robustas
* maturidade

---

### Negativas

* menor flexibilidade para dados não estruturados

---
