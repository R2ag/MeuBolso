# 📄 ADR-018 — Configuração via variáveis de ambiente

---

## Status

Aceito

---

## Contexto

O sistema precisa ser configurável sem alterar código.

---

## Decisão

Utilizar:

```text
Variáveis de ambiente para configuração
```

---

## Consequências

### Positivas

* flexibilidade
* separação entre código e configuração
* compatível com cloud

---

### Negativas

* necessidade de gerenciamento seguro de segredos

---
