# 📄 ADR-007 — Uso de Design System baseado em PrimeNG

---

## Status

Aceito

---

## Contexto

Precisamos acelerar o desenvolvimento do frontend com consistência visual.

---

## Decisão

Adotar:

```text
PrimeNG + tema customizado
```

---

## Consequências

### Positivas

* grande quantidade de componentes
* produtividade alta
* ideal para dashboards

---

### Negativas

* necessidade de padronização visual
* dependência da biblioteca
