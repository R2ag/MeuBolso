# 📄 ADR-025 — Versão do Spring Boot

---

## Status

Aceito

---

## Contexto

O framework principal do backend deve estar alinhado com versões modernas e compatíveis com o Java escolhido.

---

## Decisão

Utilizar:

```text
Spring Boot 4.0.5
```

---

## Consequências

### Positivas

* suporte a recursos modernos do Spring
* melhor integração com versões recentes do Java
* melhorias de performance e segurança

---

### Negativas

* menor quantidade de conteúdo na comunidade inicialmente
* possíveis breaking changes

---
