# 📄 ADR-021 — Frontend executado em modo desenvolvimento (Node)

---

## Status

Aceito

---

## Contexto

Durante o desenvolvimento, precisamos de hot reload e feedback rápido.

---

## Decisão

Executar frontend com:

```text
Node + Angular CLI (ng serve)
```

---

## Consequências

### Positivas

* desenvolvimento rápido
* hot reload

---

### Negativas

* não otimizado para produção
