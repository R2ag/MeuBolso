# 📄 ADR-027 — Versão do PostgreSQL

---

## Status

Aceito

---

## Contexto

O banco de dados deve oferecer alta confiabilidade e recursos modernos.

---

## Decisão

Utilizar:

```text
PostgreSQL 18
```

---

## Consequências

### Positivas

* melhorias de performance
* novos recursos SQL
* maior eficiência

---

### Negativas

* necessidade de validar compatibilidade com drivers

---
