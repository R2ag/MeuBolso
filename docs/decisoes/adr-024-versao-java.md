# 📄 ADR-024 — Versão do Java

---

## Status

Aceito

---

## Contexto

O backend será desenvolvido com foco em longevidade, performance e uso de recursos modernos da linguagem.

---

## Decisão

Utilizar:

```text
Java 25
```

---

## Consequências

### Positivas

* acesso a recursos mais modernos da linguagem
* melhor performance e otimizações da JVM
* alinhamento com versões recentes do ecossistema

---

### Negativas

* possível incompatibilidade com bibliotecas antigas
* necessidade de acompanhar atualizações frequentes
