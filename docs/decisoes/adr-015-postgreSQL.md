# 📄 ADR-015 — Uso de PostgreSQL como banco de dados

---

## Status

Aceito

---

## Contexto

O sistema exige consistência, integridade e suporte a operações financeiras.

---

## Decisão

Utilizar:

```text
PostgreSQL como banco de dados principal
```

---

## Consequências

### Positivas

* forte integridade referencial
* excelente suporte a transações
* maturidade e estabilidade

---

### Negativas

* maior complexidade comparado a bancos simples
