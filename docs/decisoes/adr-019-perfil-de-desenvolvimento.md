# 📄 ADR-019 — Uso de perfil de desenvolvimento (dev)

---

## Status

Aceito

---

## Contexto

Ambientes diferentes exigem configurações diferentes.

---

## Decisão

Adotar:

```text
Profiles (Spring) — dev como padrão local
```

---

## Consequências

### Positivas

* separação clara entre ambientes
* facilidade de configuração

---

### Negativas

* necessidade de manter múltiplos perfis
