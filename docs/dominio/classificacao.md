# 🤖 Classificação Inteligente

## 🎯 Objetivo

Classificar automaticamente:

- Categoria
- Contraparte

---

## 🧠 Estratégia

Sistema baseado em múltiplas camadas:

1. Regras explícitas
2. Histórico do usuário
3. Similaridade textual
4. Modelo probabilístico (futuro)

---

## 📊 Score de confiança

- Alta (>0.9): automático
- Média (0.7–0.9): sugerido
- Baixa (<0.7): revisão obrigatória

---

## 🔁 Aprendizado

O sistema aprende com:

- Correções do usuário
- Frequência de classificações
